#

#    CLIP: <palabras clave en ingles para buscar el clip en Pexels>

#    DATA: counter | <numero> | <sufijo, ej. " CV"> | <etiqueta>

#    DATA: bars | <etiqueta> | Nombre1:valor1,Nombre2:valor2,Nombre3:valor3
#
